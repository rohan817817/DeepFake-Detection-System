# Multimodal Deepfake Detection System

## Project Overview

This project is a multimodal Deepfake detection system that combines visual and audio analysis to identify manipulated media.

## Technologies Used

* Python
* PyTorch
* OpenCV
* Streamlit
* NumPy
* Scikit-Learn

## Dataset

* FakeAVCeleb Dataset

## Features

* Visual Deepfake Detection using ResNet18
* Audio Deepfake Detection using MFCC Features
* Grad-CAM Explainability
* Confidence Score Visualization
* Streamlit-Based User Interface

## Model Performance

### Visual Model

* Accuracy: 73.5%
* Precision: 91.23%
* Recall: 52.00%
* F1-Score: 66.24%

### Audio Model

* Accuracy: 92.75%
* Precision: 95.24%
* Recall: 90.00%
* F1-Score: 92.54%

## Workflow

1. Data Preprocessing
2. Feature Extraction
3. Model Training
4. Model Evaluation
5. Explainability using Grad-CAM
6. Streamlit Deployment
